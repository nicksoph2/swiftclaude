## What to build

The Managed tier is entirely missing. This packet adds the discovery layer that finds managed settings files at the macOS platform-specific paths.

### Step 1: Create ManagedSettingsLocator

Create `ClaudeConfigManager/Infrastructure/Discovery/ManagedSettingsLocator.swift`:

- Protocol `ManagedSettingsFileSystem` for testability (file existence check, directory listing)
- Default implementation `FileManagerManagedSettingsFileSystem`
- `ManagedSettingsLocator` struct with injected file system
- Platform constant: `/Library/Application Support/ClaudeCode/`
- Methods:
  - `locateManagedSettingsFile() -> DiscoveredFile?` — finds managed-settings.json
  - `locateManagedSettingsDropIns() -> [DiscoveredFile]` — finds managed-settings.d/*.json sorted alphabetically
  - `locateManagedMcpFile() -> DiscoveredFile?` — finds managed-mcp.json
  - `locateAll() -> ManagedDiscoveryResult` — combines all of the above with issues

### Step 2: Extend Discovery Models

In RootResolutionModels.swift, add:
- `DiscoveredFileKind` cases: `.managedSettingsJSON`, `.managedSettingsDropIn`, `.managedMcpJSON`
- `DiscoveredDirectoryKind` case: `.managedSettingsRoot`

### Step 3: Integrate with WorkspaceScanner

Update `WorkspaceScanner.scan()` to call `ManagedSettingsLocator.locateAll()` and include managed files in the scan result. Add a `managedWorkspace` property to `ScanResult` alongside the existing `userWorkspace` and `projectWorkspaces`.

### Step 4: Tests

Create `ClaudeConfigManagerTests/Discovery/ManagedSettingsLocatorTests.swift`:
- `testLocatesManagedSettingsFile`: mock file system with the file present
- `testLocatesDropInFiles`: mock with 3 files, verify alphabetical order
- `testLocatesManagedMcpFile`: mock with file present
- `testMissingDirectoryReturnsEmpty`: mock with no /Library/Application Support/ClaudeCode/
- `testInaccessibleDirectoryProducesWarning`: mock that throws permission error
- `testIntegrationWithWorkspaceScanner`: verify managed files appear in ScanResult

Use the same mock/protocol injection pattern as existing WorkspaceScannerTests.
