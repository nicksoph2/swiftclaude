## Build and test (quick reference)

Run from `ClaudeConfigManager/`:

```bash
xcodebuild test -project ClaudeConfigManager.xcodeproj -scheme ClaudeConfigManager \
  -destination 'platform=macOS' -quiet 2>&1 | tail -30
```

---

## Critical rules

- **Never edit `project.pbxproj`** — it is generated by XcodeGen from `project.yml`.
- **Run `xcodegen generate`** from `ClaudeConfigManager/` after creating new `.swift` files.
- **Never break existing tests** — run the full suite after every change.
- **Never remove or rename public API** without backward compatibility.
- **All file writes must be atomic**: write temp → `fsync` → `rename` (use `AtomicFileWriter`).
- Use `JSONValue` for all untyped JSON — never `Any`.
- Scope colours live only in `Core/ScopeColorScheme.swift` — never hard-code them.
- Mock/stub types go in the test target only, never the main target.
- Every new type name must be unique across the module — grep before naming.
- If blocked on something requiring human input, write a `Documents/<topic>-BLOCKED.md` and stop.

---

## Communication style

- Minimal output: no preamble, no explanation of what you are about to do.
- Report success or failure only.
- Ask clarifying questions only if genuinely blocked.
- No code diffs or file paths unless explicitly requested.
