Settings

Open Settings from the menu bar (Claude Config Manager → Settings or ⌘,). The Settings window has three tabs.

Global Root

Manages access to your global Claude folder (~/.claude). Shows the current authorised path and its source (Default or Custom). You can:

  • Use Recommended Folder — switch back to the default ~/.claude path
  • Choose Different Folder — authorise a custom location via the file picker

Folder access uses macOS security-scoped bookmarks, so the app remembers your choice across launches.

Projects

Lists all registered project roots. Each project shows its display name, preferred path, and created/updated timestamps. You can:

  • Add Project — register a new project directory
  • Remove — unregister a project (does not delete any files)
  • Select — switch to a different project for pipeline resolution

Schema

Controls automatic schema updates from the Claude Code settings schema endpoint:

  • Toggle auto-update — enable or disable remote schema fetching
  • Last updated — when the schema was last successfully fetched
  • Refresh Now — manually trigger a schema fetch
  • Status indicator — shows success, failure, or idle state

When enabled, the app checks for newly added settings keys from the server. The schema is cached locally so the app works fully offline.

Note: Schema updates only add awareness of new configuration keys. They don't change any of your actual configuration files.
