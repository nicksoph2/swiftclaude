Keyboard Shortcuts

Claude Config Manager supports global keyboard shortcuts for fast navigation.

Shortcut Action
⌘F Open Global Search
⌘R Refresh pipeline (re-scan and re-resolve all configuration)
⌘1 Go to Dashboard
⌘2 Go to Resolved Config
⌘3 Go to Permissions Inspector
⌘4 Go to Issues
⌘5 Go to Pipeline View
Esc Close search overlay
Tip: These shortcuts work from any view in the app. You don't need to be in a specific location to navigate with keyboard shortcuts.
