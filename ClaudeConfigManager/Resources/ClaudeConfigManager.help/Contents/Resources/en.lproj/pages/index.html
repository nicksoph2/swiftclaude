What This App Does

When Claude Code runs, it reads configuration from several locations on disk — enterprise-managed policies, your global ~/.claude folder, project-level files, and session state. These sources are layered together with a strict precedence order to produce the final active configuration.

Claude Config Manager makes this entire process visible. It scans those same files, parses them, and walks you through each stage of assembly so you can see exactly why a particular setting has the value it does.

Need More Help?

Use ⌘F inside the app to search across all configuration keys, files, and servers. You can also access the pipeline intro animation from the Help menu at any time.
